Component Overview

This UI demonstrates how the Element Locator Engine reacts when a Playwright/Selenium-style RPA bot fails due to UI changes. The Orchestrator simulation triggers a failure on a sample login page, and this component analyses:

  • HTML snapshot (DOM structure)
  • Page screenshot (for Computer Vision)
  • Bot context (intended element role & expected text)

It then proposes new locators with confidence scores using DOM analysis, Computer Vision signals, and a trained ML model.

View Last Report

Tip: During PP1, click Run Failure Demo while explaining the pipeline: Orchestrator → Locator Engine → Report.

Pipeline Summary

  1. 1
    Bot Failure Detected

    A demo Selenium bot fails to find the old “Login” button on login_v2_changed.html.

  2. 2
    Context Sent by Orchestrator

    Page URL, HTML snapshot, screenshot, and metadata (role = primary_action, expected text = “Login”) are passed to this component.

  3. 3
    Locator Engine Analysis

    DOM layer extracts all interactive elements, CV layer estimates visual similarity, and an ML model ranks candidates with confidence scores.

  4. 4
    Locator Report Generated

    Highest-confidence locator is selected and exposed as JSON to the future Code Healing Engine.
